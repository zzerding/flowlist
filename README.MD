# Flowlist

一个受 Workflowy 启发的本地优先大纲工具。单份代码响应桌面、平板和手机布局，并可作为 PWA 安装。

## 功能

- 无限层级大纲：`Enter` 新建，`Tab` 缩进，`Shift + Tab` 减少缩进
- 点击圆点聚焦任意分支，面包屑返回上级
- 搜索、折叠、待办、拖拽排序
- 自动保存到浏览器，离线可用
- 明暗主题和移动端导航

## 运行

```bash
pnpm dev
```

打开 <http://localhost:5173>。

## 验证

```bash
pnpm test
```

数据只保存在当前浏览器的 IndexedDB 中，清除站点数据或使用隐私模式可能导致丢失。账号同步与多人协作尚未实现。
